States & ages

States can overlap. Select several to match any. Counts follow search and workstream. “Contributor review” means an actual pending decision on a linked candidate. “Maintainer review” means an open PR without reported approval or changes requested. “Awaiting import” means approved or ready-to-pull with no current public import; checks may still be failing or unknown. “Import PR open” identifies an existing exact-source import, not progress toward merge. “Waiting for merge” additionally requires nondraft, conflict-free source and import heads with complete green visible checks; it is an observation, not merge authorization. Failure labels identify the source or exact import PR; details link reported failing checks.

“obs” shows how long ago this state was first observed on the same revision, as of the snapshot. The transition may be older; continuity between scans is unknown. Exact GitHub merge/close times have no “obs”. Ages do not come from comment or update times. Select an item for dated evidence.
