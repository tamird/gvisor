The prefix implementation avoids cloning unread packet views on a partial
read. Both versions use the same NIC teardown. Each sample transferred
and verified 4 MiB at MTU 1500, with GRO and GSO disabled. Time per
operation is normalized to 1 MiB. All 16 pairs ran on two CPUs of an
AMD EPYC 7763. The first implementation alternated between pairs.
